## Learned Workspace Facts

- Kainos Player is a Kotlin Multiplatform Compose app (`androidApp`, `desktopApp`, `shared`) under package `com.universalmusic.player`; `main` uses SQLDelight (`kainos.db`, schema version 10 from migrations `1.sqm`–`9.sqm`; Android versionCode = schemaVersion * 100_000 + commit count, so Android refuses an older-schema build as a downgrade, and desktop names a newer database) for library, playlists, session, play history, loudness and local scan snapshots; legacy JSON imports once and stays as `*.json.migrated`; settings, tokens, and caches remain files/SharedPreferences; desktop data lives under `~/.universal-music-player/`; shared Compose UI is Material 3 with multi-scheme Appearance settings; shared `PlayerSession` owns queue, metadata, and transport; shuffle uses a separate `shuffleOrder` (queue-entry identity for Play next); `playQueueIndex` and Repeat All wrap reshuffle with the chosen/wrap track first while skip next/prev walk the current order; `PlayerSession` is confined to one thread (`confineTo` = `Dispatchers.Main.immediate`, i.e. Android main looper / Swing EDT, fallback single worker): public calls run inline on that thread and are posted from MPRIS/D-Bus or background threads, while resolve/enrich/`engine.play` run in `workContext` (Default) with generation re-checks; terminal failures skip each queue entry at most once per unsuccessful pass (bounded under Repeat All, Repeat One ignored for failure-skip); `docs/CURRENT_STATE.md` tracks playback/Spotify/YouTube status
- Android test phone (Poco F7 Ultra, HyperOS) is reached over wireless adb: `adb devices -l` lists `_adb-tls-connect` entries; install with `adb -t <transport_id> install -r release/<apk>` (in-place update keeps settings, library folders, hearts and logs)
- Desktop runs need JDK 17 (commonly `~/.jdks/temurin-17`) via `./gradlew :desktopApp:run`; installable launcher is `kainos-player` (Caelestia / `.desktop` entry) which starts Temurin `java` on the packaged jars and only rebuilds `:desktopApp:createDistributable` with `--rebuild` / `KAINOS_REBUILD=1` (`scripts/kainos-player-dev` always rebuilds), so a plain launch can run a stale package (the Compose/jpackage native stub SIGSEGVs here because jlink uses `--strip-native-commands`); run logs go under `logs/desktop-run-*.log`, with `logs/desktop-run-latest.log` as the latest GUI symlink (`--hub-only` runs write `logs/hub-run-*.log` / `logs/hub-run-latest.log`); per-connection Home sync TLS/probe lines are `PlaybackTrace.debug`, off unless `KAINOS_TRACE_DEBUG=1` on desktop
